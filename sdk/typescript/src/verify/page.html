tracekit verify

Checks that an AI agent's evidence bundle (.tkb) is intact and signed by the signer you trust. Runs in this page: nothing to install.

Your file never leaves this page (the browser blocks all network access for it).

bundle: none chosen

trust (optional): none

The trust file (trust.json, from the sender) names the signer key and witnesses you trust. Without it the page still finds changed or missing records, but can't tell whose signer made the bundle.
